# `station_index.csv` — column reference

Generated by `scripts/list_stations.py` (via `scripts/routes_lib.py`) from
`matched_data_flat_2020_01.parquet` + `metadata_closest_ems_to_train_stations.csv`.
Regenerate with:

```bash
source .venv/Scripts/activate
python scripts/list_stations.py
```

One row = one **station** (`stationShortCode`), covering every station the
parquet's trains visit that month — passenger stations and freight/technical
stops alike. Delay statistics use the exact same definitions, buckets and
clamped-to-0 convention as `routes_index.csv` (see
`data/derived/routes_index.README.md`) — the only difference is the
grouping: here it's **just the station**, across every route and train type
that passes through it, not one route at a time.

If you want a station's delay *within one specific route* instead (e.g. "how
late does Pasila run on the Helsinki–Turku service specifically"), that's the
`stops` column in `routes_index.csv`, not this file.

"On time" = ≤ 5 min late. Delay severity buckets: **on time** (≤ 5 min),
**minor delay** (5–15 min), **major delay** (> 15 min).

## Identity

| Column | Meaning |
|---|---|
| `code` | Station short code. |
| `name` | Station name, read from the parquet's own (mojibake-fixed) `stationName` — populated for every station, even the few missing from the metadata CSV below. |
| `lat` / `lon` | Coordinates from `metadata_closest_ems_to_train_stations.csv`. `null` for the 7 stations not in that CSV (see Notes). |
| `passengerTraffic` | From the same metadata CSV. `null` (not `False`) for those same 7 stations — absence of data, not a known "no". |

## Route context

| Column | Meaning |
|---|---|
| `appearances` | How many train runs stop at this station at all (any event type — ARRIVAL or DEPARTURE-only, e.g. this station being a run's origin). |
| `distinctRoutes` | Number of distinct routes (origin × destination × trainType) whose runs pass through this station. A rough measure of how central the station is to the network. |
| `distinctTrainTypes` | Comma-separated list of train types (`IC`, `S`, `HDM`, …) that stop here. |
| `firstDate` / `lastDate` | Earliest / latest `departureDate` among runs passing through. |
| `month` | Source month (`YYYY-MM`). |

## Delay statistics

Computed from this station's own `ARRIVAL` events only, across **all** runs
of **all** routes that stop here — same clamped-to-0-for-early-arrivals
convention as `routes_index.csv`.

| Column | Meaning |
|---|---|
| `runs` | How many arrivals at this station have a usable delay value. Roughly `appearances` minus however often this station is a run's origin (which has no ARRIVAL event) — see Notes. |
| `avgDelay` / `medianDelay` / `p90Delay` / `maxDelay` / `delayStdDev` | Mean, median, 90th percentile, single worst delay, and spread (minutes) of arrivals at this station. |
| `onTimePct` / `pctMinorDelay` / `pctMajorDelay` | % of this station's arrivals in each severity bucket. Sums to 100% (rounding aside). |
| `avgMinorDelay` / `avgMajorDelay` | Mean delay within each bucket, at this station. `null` if no arrivals fall in that bucket. |
| `cancelledPct` | % of this station's `ARRIVAL` events (cancelled ones included in the denominator) that were cancelled. |

## Notes / edge cases

- **7 stations have `null` `lat`/`lon`/`passengerTraffic`**: `HMK` (missing
  from the metadata CSV too — a known gap, see CLAUDE.md) and 6 Russian
  border/onward stations (`BSL`, `MVA`, `PTL`, `PTR`, `TVE`, `VYB` — Vyborg,
  Moscow, St Petersburg, Tver, Buslovskaja) that this month's trains run
  through but which aren't in a Finnish-stations CSV.
- **A pure-origin station's `runs` can be well below its `appearances`.**
  `HKI` (Helsinki), for example, is the origin of roughly half its runs
  (no ARRIVAL event there) and the destination of the other half — so
  `runs` sits at about half of `appearances`. This is expected, not missing
  data.
- Row count is **409** — every distinct `stationShortCode` in the source
  parquet (see CLAUDE.md's "Stations" data fact).
